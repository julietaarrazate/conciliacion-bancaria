## 3. DESCRIPCIÓN SINTÉTICA

Sistema web multi-tenant de gestión financiera y contable que automatiza la
conciliación bancaria, la generación de asientos contables, la gestión de
cheques, pagos, caja, liquidaciones y reportería. Incorpora un motor de
conciliación con scoring multi-criterio, un motor contable de asientos
automáticos, aprendizaje por patrones, OCR de comprobantes y un asistente
de inteligencia artificial conversacional.

**Componentes:**
- Backend API REST (FastAPI + Python)
- Frontend web (React + TypeScript, PWA instalable)
- Aplicación móvil (React Native + Expo)
- Base de datos relacional (PostgreSQL) con migraciones versionadas
