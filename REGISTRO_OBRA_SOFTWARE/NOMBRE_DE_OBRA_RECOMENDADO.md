## 2. RECOMENDACIÓN

### Para el expediente de registro de software

**Usar: `Sistema Integral de Gestión Financiera, Contable y Empresarial`**

Razones:
1. Es el nombre con mayor poder descriptivo del alcance real del sistema (finanzas + contabilidad + multi-empresa).
2. Es el que ya figura en todos los documentos generados — cambiar ahora implicaría editar 9 archivos.
3. Es apropiado para los formularios de la DNDA (Dirección Nacional del Derecho de Autor) y organismos equivalentes.
4. No limita el alcance del sistema a "conciliación bancaria" como lo haría el nombre del repositorio.

### Para el nombre comercial / marcario (futuro)

**Reservar: `Cuadra`**

Como nombre de fantasía para uso comercial, con registro marcario separado. El expediente de software puede consignar ambos:
- **Nombre de la obra:** Sistema Integral de Gestión Financiera, Contable y Empresarial
- **Denominación de trabajo:** Cuadra *(sin registro marcario vigente)*
