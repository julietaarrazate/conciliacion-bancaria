# /dev — Iniciar sesión de desarrollo

Antes de empezar cualquier tarea de desarrollo, ejecutar este checklist:

1. Leer `CLAUDE.md` (solo la sección del módulo que vamos a tocar)
2. Leer `docs/errors-log.md` para no repetir errores conocidos
3. Identificar el módulo: backend / frontend / mobile / database
4. Leer el `CLAUDE.md` de ese módulo
5. Confirmar con el usuario qué tarea específica vamos a hacer

No cargar código que no sea necesario para la tarea. Preguntar si algo no está claro.
