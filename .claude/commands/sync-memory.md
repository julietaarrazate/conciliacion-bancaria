# /sync-memory — Actualizar memoria del proyecto

Ejecutar al final de cada sesión importante:

1. Revisar qué cambió en esta sesión
2. Actualizar el CLAUDE.md del módulo afectado con:
   - Patrones nuevos descubiertos
   - Gotchas o problemas encontrados
   - Estado actual actualizado
3. Si hubo errores → agregar a `docs/errors-log.md` con:
   - Descripción del error
   - Causa raíz
   - Solución aplicada
   - Cómo evitarlo en el futuro
4. Si hubo decisiones de arquitectura → agregar a `docs/architecture.md`
5. Actualizar la tabla de estado en `CLAUDE.md` principal
6. Agregar línea en "Historial de sesiones" con fecha y resumen

El objetivo: la próxima sesión empieza más inteligente que esta.
