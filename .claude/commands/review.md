# /review — Revisar código antes de commit

Revisar el código modificado siguiendo este checklist:

1. ¿El código hace exactamente lo que se pidió?
2. ¿Hay tests para lo nuevo?
3. ¿Se rompió algo existente?
4. ¿Los endpoints nuevos están en `docs/api-contracts.md`?
5. ¿Hay errores nuevos que agregar a `docs/errors-log.md`?
6. ¿Hay algo que actualizar en el CLAUDE.md del módulo?

Reportar cualquier problema encontrado antes de confirmar el commit.
